プライバシーポリシー

対象アプリケーション: claudecode（Google OAuth クライアント） / 最終更新: 2026-09-14

本アプリケーション「claudecode」（以下「本アプリ」）は、開発者（角井 勇哉）が個人のタスク・予定管理のために作成し、開発者自身のみが利用するものです。本ページでは、本アプリが Google API を通じて取得するデータの取り扱いを説明します。

取得するデータ

  • Google Tasks: タスクリストおよびタスク（タイトル・期限・完了状態・メモ）の読み取りと作成・更新・完了
  • Google カレンダー: 予定（タイトル・日時・参加状況）の読み取りと、本アプリが作成した作業ブロック予定の作成・更新・削除
  • メールアドレス: 認証したアカウントの識別のためのみ

利用目的

取得したデータは、開発者本人の日次計画の作成（空き時間へのタスク配置）と、タスクの同期のためにのみ使用します。広告、分析、プロファイリング、第三者への提供には一切使用しません。

データの保存と共有

  • 本アプリはサーバーを持たず、開発者のローカル端末上で動作します。認証トークンは開発者の端末内にのみ保存されます
  • Google から取得したデータを第三者に送信・販売・共有することはありません
  • データはローカルのテキストファイル（タスク一覧・日報）として開発者の端末およびプライベートリポジトリに保存されることがあります

Google API サービスのユーザーデータに関するポリシーへの準拠

本アプリによる Google API から取得した情報の利用は、Google API Services User Data Policy（Limited Use の要件を含む）に準拠します。

アクセスの取り消し

本アプリへのアクセス許可は、Google アカウントの「サードパーティ製のアプリとサービス」からいつでも取り消せます。取り消し後、本アプリは当該アカウントのデータにアクセスできなくなります。
